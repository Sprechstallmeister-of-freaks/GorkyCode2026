# Ритм — голосовой ассистент задач и встреч (ядро без LLM)

Тестовое задание: отделённая от модели, запускаемая локально **бизнес-логика органайзера**, FastAPI, SQLite, инструменты для будущего LLM-agent, минимальный веб-интерфейс и ограниченный детерминированный режим диалога. Код с тестами; модель, API-ключи и Ollama **не нужны**.

> **Честный статус:** работа с задачами/встречами, CRUD, API, локальное хранение, импорт 1000 событий, голосовой ввод через браузер и шаблонные диалоги работают. **Свободное понимание любого естественного языка, полноценный семантический поиск, LLM tool calling и автоматическая compaction пока не реализованы.** Их добавим отдельным адаптером поверх готовой бизнес-логики.

## Запуск на Windows 10/11

1. Установите [Python 3.11+](https://www.python.org/downloads/windows/) с опцией **Add Python to PATH**. Интернет нужен только для однократной установки Python-зависимостей.
2. Распакуйте ZIP в папку без ограничений на запись, например `C:\Projects\ritm`.
3. Дважды нажмите **`start_windows.bat`**. Он создаст `.venv`, установит зависимости и запустит сервер.
4. Откройте **http://127.0.0.1:8000**. Документация REST API: **http://127.0.0.1:8000/docs**.
5. Для остановки нажмите `Ctrl+C` в окне сервера.

Альтернативно в PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.py
```

Если PowerShell блокирует `Activate.ps1`, используйте `\.venv\Scripts\python.exe -m pip install -r requirements.txt`, затем `\.venv\Scripts\python.exe run.py`. Не требуется менять системную политику PowerShell.

При первом запуске автоматически импортируются записи из `data/events.csv` в `assistant.db`. Повторный запуск **не создаёт дубликаты**. Созданные и изменённые записи не теряются при перезапуске. Для чистого старта удалите файл `assistant.db` **при выключенном приложении** (потеряются все изменения) или укажите новый путь `ASSISTANT_DB`.

### Настройки

По умолчанию используется часовой пояс `Europe/Moscow`. Чтобы переключиться на ваш, перед запуском в PowerShell:

```powershell
$env:ASSISTANT_TIMEZONE="Europe/London"
$env:ASSISTANT_DB="C:\Projects\ritm\assistant.db"
python run.py
```

Или измените `start_windows.bat`, добавив `set "ASSISTANT_TIMEZONE=Europe/London"` после `cd`. **Часовой пояс нужно выбрать ДО первого импорта**: он сохраняется у каждой записи. На Windows для баз IANA поставляется зависимость `tzdata`.

Другие настройки: `ASSISTANT_IMPORT_SEED=0` — отключить загрузку CSV, `ASSISTANT_SEED_CSV` — задать другой исходный CSV. `data/events.csv` намеренно включён в архив.

## Что можно проверить

* Кнопка **Новое событие**: задача без даты или с датой, встреча с обязательными датой/временем, напоминание.
* **Расписание**: фильтр по датам и типам, поиск по названиям, пагинация, отметка выполнения, редактирование и отмена.
* **Диалог** (упрощённый режим, не LLM): «Напомни мне завтра в 10 утра позвонить Ивану», «Добавь встречу с командой завтра», затем «в 15:00», «Что у меня сегодня?», «Найди задачу про договор», «Перенеси её на пятницу» после однозначного выбора.
* **Диктовка**: кнопка микрофона при наличии Web Speech API в Chrome/Edge; голос распознаётся браузером и подставляется в поле текста. Есть опциональная озвучка ответа браузером.
* **Инструменты**: `GET /api/tools` возвращает строгие схемы для будущего LLM; в модуле `assistant/tools.py` есть безопасный исполнитель.

Управление диалогом в деморежиме намеренно ограничено. Для неклассифицированных фраз интерфейс прямо сообщает о необходимости LLM.

## Архитектура

```
Browser (vanilla JS, SpeechRecognition, speechSynthesis)
                |
           REST /api/*
                |
  FastAPI --> RuleDialogue (временный fallback)
                |
  ToolRegistry   |    <-- будущий LLM Adapter
          \      |
              Planner
           /    |    \
  validation   search   conflict checks
                |
             SQLite
        events/sessions/messages
```

| Модуль | Ответственность |
| --- | --- |
| `assistant/models.py` | Pydantic-схемы, строгая валидация входных аргументов |
| `assistant/database.py` | SQL-схема, транзакции `BEGIN IMMEDIATE`, индексы, WAL |
| `assistant/service.py` | Бизнес-логика, конфликты встреч, статусы, CSV, хранение диалога |
| `assistant/search.py` | Оффлайн поиск с нормализацией и нечёткими совпадениями (НЕ embeddings) |
| `assistant/dates.py` | Детерминированный разбор типовых русских дат/времени |
| `assistant/dialogue.py` | Ограниченный временный обработчик типовых команд и уточнений |
| `assistant/tools.py` | Шесть инструментов с JSON Schema, изолированная диспетчеризация |
| `assistant/api.py` | HTTP маршруты и перевод доменных ошибок в 404/409/422 |
| `web/*` | Адаптивный UI без сборщика и внешнего JS CDN |
| `tests/*` | Автоматические проверки без сетевых вызовов и LLM |

Подробности и план интеграции LLM см. [ARCHITECTURE.md](ARCHITECTURE.md).

## API в двух примерах

Создать встречу:

```powershell
$body = @{kind="meeting"; title="Планёрка"; scheduled_date="2026-11-05"; scheduled_time="15:00"; duration_minutes=60} | ConvertTo-Json
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/api/events -ContentType 'application/json' -Body $body
```

Посмотреть задачи за период:

```powershell
Invoke-RestMethod 'http://127.0.0.1:8000/api/events?from_date=2026-11-02&to_date=2026-11-08&kind=task'
```

Дополнительно: `PATCH /api/events/{id}`, `DELETE /api/events/{id}` (мягкая отмена), `GET /api/search?q=договору`, `POST /api/chat`, `GET /api/sessions/{session_id}/history`, `GET /api/tools`.

Ответы на ошибки: `404` — запись не найдена, `409` — конфликт встречи или устаревшая версия, `422` — невалидные аргументы. `expected_version` в изменениях предотвращает случайную перезапись параллельных изменений.

## Данные и намеренные ограничения

Исходный CSV содержит **ровно `id,date,time,text`**, без поля типа записи. Поэтому все 1000 импортированных элементов сохраняются как `task` с источником `csv` и исходным внешним ID. **Мы не пытаемся угадать по тексту, что запись была встречей или напоминанием**. Импорт атомарен, его можно повторять. Изменение CSV не перезаписывает уже импортированные события.

* Встреча/напоминание требуют даты и времени; у задачи срок необязателен.
* Встречи по умолчанию занимают 60 минут; пересечения запрещаются, включая переход через полночь. Это намеренное продуктовое решение для прототипа.
* Отмена — soft delete (`status=cancelled`). Запись остаётся доступна через `get`, по умолчанию исключается из списков.
* Все датированные операции используют IANA timezone события. Несуществующее локальное время в DST отклоняется; для неоднозначного осеннего часа используется первое вхождение (`fold=0`).
* Поиск поддерживает нормализацию `ё/е`, распространённые окончания и небольшие опечатки, но **не является семантическим**.
* Фоновых будильников, push-уведомлений, внешней синхронизации календаря, повторяющихся событий, ролей и нескольких учётных записей **нет**.
* Веб-приложение и API не аутентифицированы: сервер по умолчанию слушает только `127.0.0.1`. 
* Web Speech API зависит от браузера и может использовать облачное распознавание. Локальная бизнес-логика не означает офлайн STT. Не храните секретные данные, если используете браузерный голосовой ввод без проверки его политики.
* История диалога сохраняется как есть в SQLite. Compaction пока не нужна (нет LLM); при подключении модели нужна отдельная подсистема context manager.

## Тесты

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тестируются создание и валидация, транзакции, конфликты и границы времени, DST, статусы, оптимистичные версии, API, tools, русские даты, уточняющий диалог, хранение и идемпотентный CSV-импорт. Тесты изолированы во временных базах.
